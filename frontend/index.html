    Sensor states

    AVAILABLE
    A real reading was returned by a supported local source.
    UNAVAILABLE
    No current value is available from the source.
    UNSUPPORTED
    The hardware or operating system does not expose this reading through supported interfaces.
    PERMISSION_RESTRICTED
    Windows denied access because the required permission is not available.
    TEMPORARILY_DISCONNECTED
    The device or sensor source is temporarily disconnected.
    ERROR
    The source returned an error; check its live details on the Sensors page.
    NOT_INITIALIZED
    The provider has not completed its first discovery or sample.

      No kernel driver or MSR access is used. Exact core temperature, package power, and fan RPM are not promised; they are shown only if a supported source reports them.

      Privacy and stored data

      Sensor readings and their states are stored locally in the history database under the application data folder. The database uses raw readings and 1-minute and 5-minute aggregates. The app does not store passwords or send monitoring data online.

      Use History → Clear history to remove recorded samples. Settings controls history recording, retention, and the database size limit. Settings are saved in the local data folder.

      Online device-fact lookup is off by default and is the only feature that can use the network.
