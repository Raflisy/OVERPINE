Enable CPU temperature and power sensors

  1. Download LibreHardwareMonitor from its official GitHub releases.
  2. Run LibreHardwareMonitor as Administrator.
  3. Choose Options → Remote Web Server → Run and keep it on port 8085.

OVERPINE connects only to 127.0.0.1:8085. Sensors not exposed by the hardware or driver remain unavailable.
